# Connect Four（四目並べ）

## ゲーム概要
縦・横・斜めに先に4つの駒を並べたプレイヤーが勝利するゲームです。

## 動作環境
Python 3

## 起動方法
Pythonをインストールし、ターミナルで以下のコマンドを実行します。

```bash
python connect_four.py
```

## 操作方法
- 1〜7：駒を置く
- U：一手戻す
- R：ゲームをリセットする
- Q：ゲームを終了する

## 追加・改良した機能
Undo機能を追加しました。
Uキーを入力すると、直前の操作を取り消すことができます。
